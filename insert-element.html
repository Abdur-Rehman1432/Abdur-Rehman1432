⏱ Complexity

Insert operation in an array takes O(n) time in the worst case, since all elements after the position must be shifted one step to the right.

💡 Learning Tips

  • Arrays store elements in contiguous memory locations.
  • Insert shifts elements at and after the index one step to the right.
  • Delete shifts elements to the left to fill the gap.
  • Update just replaces the value at the selected index.
  • Array indices start from 0.
